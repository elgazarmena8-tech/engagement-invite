# دعوة خطوبة — روان & أحمد

موقع دعوة خطوبة فاخر وأنيق، مبني بالكامل بـ HTML / CSS / JavaScript بدون أي مكتبات خارجية (باستثناء خطوط Google Fonts).

## هيكل المشروع

```
engagement-invite/
├── index.html      ← الصفحة الرئيسية وكل النصوص والأقسام
├── style.css       ← كامل التصميم، الألوان، الخطوط، التجاوب
├── script.js       ← العد التنازلي، الأنيميشن، البتلات، زر الموسيقى
├── assets/
│   └── music.mp3   ← ضع ملف الموسيقى الخاص بك هنا (غير مرفق)
└── README.md
```

## كيفية التشغيل محليًا

1. افتح مجلد المشروع.
2. أضف ملف موسيقى هادئ بصيغة MP3 باسم `music.mp3` داخل مجلد `assets/`
   (الكود يشير مسبقًا إلى `assets/music.mp3`، لذا لا حاجة لتعديل أي كود).
3. شغّل المشروع عبر أي سيرفر محلي بسيط، مثال:
   - في الطرفية: `python3 -m http.server 8080` ثم افتح `http://localhost:8080`
   - أو افتح `index.html` مباشرة في المتصفح (بعض المتصفحات تمنع تشغيل الصوت التلقائي عند الفتح المباشر بدون سيرفر — الموقع سيعرض زر التشغيل تلقائيًا في هذه الحالة).

## ملاحظات مهمة

- **الموسيقى**: إذا منع المتصفح التشغيل التلقائي، سيظهر زر الموسيقى العائم في الزاوية بحالة "متوقف" ليضغط عليه الزائر يدويًا — لا حاجة لأي تعديل إضافي.
- **تغيير الموسيقى لاحقًا**: فقط استبدل ملف `assets/music.mp3` بأي ملف MP3 آخر بنفس الاسم.
- **تعديل التاريخ/العد التنازلي**: التاريخ المستهدف موجود في أول سطر داخل دالة `initCountdown()` في ملف `script.js`.
- **الخطوط**: يستخدم الموقع Aref Ruqaa / Amiri للأسماء والعناوين الفنية، و Cairo للنصوص العامة، وكلها من Google Fonts (تتطلب اتصال إنترنت عند التحميل الأول).
- التصميم متجاوب بالكامل: موبايل، تابلت، ديسكتوب، وشاشات كبيرة، مع دعم كامل للاتجاه من اليمين لليسار (RTL).
